WORK 01

河川水位予測モデル構築

河川水位の時系列データを対象とした機械学習モデルの設計・実装・学習・評価を担当。
時系列データに対する帰納バイアスとして微分方程式を組み込み、モデルのブラックボックス性を軽減した予測モデルを構築。
また、未来の水位予測では多様な特徴量が必要となる一方、実運用において将来時点の全ての特徴量を取得することは困難である。そこで、取得できない特徴量による不確実性をノイズとしてモデル化し、確率微分方程式（SDE）を組み込むことで、予測の不確実性を考慮したモデルを設計・構築した。

Model : DNN
Using : PyTorch / Pandas
Method : Bootstrap sampling / Inductive bias (SDE)

WORK 04

確率推定モデル構築

2値分類タスクに中心極限定理を組み合わせた、統計学的に整合性のある機械学習モデルの設計・実装・学習・評価を担当。
従来の2値分類モデルの出力確率が必ずしも真の確率を意味しないという課題に対し、データ駆動で確率分布を推定する手法を構築。中心極限定理に基づき、推定値を正規分布として扱うことで、確率の推定および数値計算を可能にした。

Model : DNN
Using : PyTorch
Method : Bootstrap sampling / Inductive bias (Central Limit Theorem)
